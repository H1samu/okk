# Hismar Check 

Веб-приложение (Progressive Web App) для управления электронными журналами, чек-листами и контроля качества (включая стандарты НАССР/HACCP). Предназначено для оптимизации ежедневных обходов, санитарного контроля и учета на производственных и кулинарных участках.

## 🚀 Основные возможности

- **Система авторизации и ролей**: Разграничение прав доступа (например, "Администратор", "Сотрудник кулинарии") с периодической фоновой проверкой токена через сервер.
- **Каталог чек-листов**: Удобный поиск по названию или коду, автоматическая фильтрация по доступным конкретному пользователю журналам.
- **Избранное**: Возможность добавлять часто используемые журналы в избранное (сохраняется локально в браузере).
- **Интеграция с экосистемой Google**: 
  - Автоматическая генерация ссылок с предварительным заполнением (prefill) для Google Forms.
  - Прямые ссылки на соответствующие Google Sheets для просмотра накопленных данных.
  - Поддержка QR-кодов для быстрого доступа к формам (через Google Drive ID).
- **Офлайн-режим (PWA)**: Поддержка Service Worker (`sw.js`) для кэширования ресурсов и стабильной работы при нестабильном интернет-соединении.
- **Адаптивный дизайн**: Оптимизирован для использования на мобильных устройствах и планшетах непосредственно на рабочем месте.

## 🛠 Технологический стек

- **Frontend**: HTML5, Vanilla JavaScript (без тяжелых фреймворков для максимальной скорости работы и простоты поддержки).
- **Backend / Хранение данных**: Google Apps Script (в качестве API-шлюза), Google Forms (сбор данных), Google Sheets (хранение и аналитика).
- **PWA**: Service Workers, Web App Manifest.
- **Стили**: Встроенный CSS с использованием CSS-переменных для легкой кастомизации тем и поддержки единого стиля.
